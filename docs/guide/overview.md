# 项目概览

Ant Design X 是一个面向 AI 应用的 UI 组件库，专为构建现代化 AI 对话界面而设计。

## 什么是 Ant Design X

Ant Design X 是 Ant Design 团队推出的垂直领域组件库，专注于 AI 应用场景。它提供了一系列精心设计的组件，帮助开发者快速构建高质量的 AI 对话界面。

### 核心特性

- **AI 原生设计**：专为 AI 对话场景设计的组件，如 Bubble、Sender、ThoughtChain 等
- **现代化 UI**：遵循 Ant Design 设计语言，提供一致且美观的视觉体验
- **高度可定制**：支持主题定制、样式覆盖、行为配置
- **TypeScript 支持**：完整的类型定义，提供优秀的开发体验
- **Monorepo 架构**：清晰的包管理结构，便于维护和扩展

### 适用场景

- AI 聊天机器人界面
- 智能客服系统
- AI 助手应用
- 对话式 UI 界面
- 知识问答系统

## 与其他组件库的区别

| 特性 | Ant Design X | Ant Design | 通用 UI 库 |
|------|-------------|-----------|-----------|
| AI 场景支持 | ✅ 原生支持 | ⚠️ 需自行组合 | ❌ 无支持 |
| 对话组件 | ✅ 丰富 | ⚠️ 基础 | ❌ 无 |
| 思考过程展示 | ✅ ThoughtChain | ❌ 无 | ❌ 无 |
| 代码高亮 | ✅ CodeHighlighter | ❌ 无 | ⚠️ 需集成 |
| Markdown 渲染 | ✅ XMarkdown | ❌ 无 | ⚠️ 需集成 |

## 技术栈

- **框架**: React 18+
- **语言**: TypeScript
- **构建工具**: Father、Vite
- **文档工具**: dumi
- **样式方案**: CSS-in-JS (Ant Design 5.0+)
- **包管理**: pnpm
- **代码规范**: Biome
